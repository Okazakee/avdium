# Release notes

This file is the body of a published release. It is written at release time and
must describe implemented and validated behavior only, never aspirational
features.

## Unreleased

No release has been published. `0.1.0-dev` is a development version.

Avdium 0.1.0 is not ready: the existing-SDK manager is implemented, but real
device start, readiness, cold boot, stop and wipe have not been exercised
against a disposable device, and the selected-image creation path requires the
classic tools, which are not yet validated. See `docs/STATUS.md` for the current
state and `docs/VALIDATION.md` for what has actually been run.
